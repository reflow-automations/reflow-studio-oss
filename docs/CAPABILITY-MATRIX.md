## 1. What this document is

This matrix lists every Higgsfield model and tool id that the Reflow Studio replacement has to cover, and for each one the fal.ai endpoint, the Kie.ai model id, any other provider that is needed, how faithful the replacement is, the list price on both providers, and whether an implemented catalog model (`packages/core/src/catalog/models/*.ts`, matched on `higgsfield_ids`) already covers it. It merges the research mapping report, the independent fact-check (authoritative wherever the two conflict) and the fal/Kie API deep-dives into one place.

**Legend.** *Fidelity:* **exact** = same upstream model/version; **substitute** = different but comparable model of the same class; **approx** = product-level feature that has to be rebuilt as a pipeline or prompt system. *Verification tags (in Notes and cells):* `✓cN` = confirmed by fact-check verdict cN; **†** = cell corrected by the fact-check (the report's original value was wrong; every † is listed in §3.10); **‡** = value not in the mapping report, filled from the fact-check additions or the fal/Kie API deep-dives; `?` = unverified (memory, inference or a single search snippet; claims c9, c10, c12, c13, c15 and c19 were never checked). *Higgsfield credits:* credits Higgsfield charges per generation, observed per-generation credits (2026) or, where marked, from public snippets; 1 credit ≈ $0.033 (Ultra annual) to $0.05 (auto-refill), list $0.085, see §4 intro; "-" = not captured. *In catalog:* the `ModelDefinition.id` whose `higgsfield_ids` contains the Higgsfield id, or "-" (tool rows say which model the tool routes to).

**Prices** are USD list prices (no volume discounts) as seen in Aug-Sep 2026; Kie bills credits at **1 credit = $0.005** and its image prices drift month to month, fal bills per image / megapixel / second / 1k characters / generation. Both providers' prices change monthly: treat every figure here as a planning estimate, re-fetch `GET https://api.fal.ai/v1/models/pricing` and Kie's per-task `creditsConsumed` before they enter a cost model, and keep `pricing.verified_at` in the catalog current.

**Date:** 2026-09-05 (fal registry snapshot 2026-09-02, Kie market snapshot Aug/Sep 2026, Higgsfield MCP catalog captured live 2026-09-05).

## 2. Provider strategy

1. **fal.ai is the primary provider (~85 % of the catalog).** Every image model except Soul, every video model (Kling 3.0/Turbo/O3/4K/motion-control, Seedance 2.0/2.5, Veo 3.1, Wan 2.6/2.7/3.0, HappyHorse, Grok, MiniMax H3, FLUX 3, Gemini Omni 1.1), all audio (Seed Audio, Qwen TTS, ElevenLabs TTS/voice-changer/dubbing, MiniMax, VibeVoice, Sonilo, Mirelo, Inworld), all 3D (Meshy 5/6/7, Tripo H3.1, Hunyuan3D 3/3.1, SAM 3D), the upscalers, BiRefNet, SAM 3 video, Luma reframe, sync-lipsync v3 and the LoRA trainers are on one queue contract (`queue.fal.run`, signed webhooks, `fal.storage`, one bill). Higgsfield itself resells fal for several entries (`sonilo_music`, `mirelo_text_to_audio`, `inworld_text_to_speech` carry `provider_name: FAL`, ✓c22), so most of the replacement is re-plumbing rather than model search.
2. **Kie.ai sits behind the `ProviderRouter` as cost arbitrage and gap filler (~10 %).** Same-model prices are materially lower (Kling 3.0 pro+audio $0.135/s vs $0.168/s; Veo 3.1 fast $0.30 per 8 s vs $1.20; Grok video 720p $0.0225/s vs $0.07/s; Seedream 5 Pro $0.035-0.07 vs $0.0675-0.135; Nano Banana Pro $0.09 vs $0.15; Seedance 2.5 like-for-like ≈1.5-2× cheaper †). Unique on Kie: Suno V5/V5.5, avatars (`omnihuman-1-5`, `kling/ai-avatar-*`, `infinitalk/from-audio`), Runway Aleph, Ideogram character/reframe, Wan 2.2 Animate, Kling O3 "transformation". Risks: unofficial reseller of Google/OpenAI/Kling models (ToS and uptime exposure, self-declared "slightly lower stability"), no voice cloning/dubbing/3D/video matting/video reframe, schema drift (`multi_shots` became required, `reference_video_urls ` with a trailing space, `resultJson` is a string), 20 task creations per 10 s with 429 instead of queueing, 14-day/24-h result URLs. Every Kie binding therefore has a fal fallback and results are copied to our own storage in the webhook.
3. **Direct vendor APIs only for the few real gaps:** the **ElevenLabs official API** for voice management (instant/professional voice clone, voice library) and dubbing, and the **Google Gemini API** for video understanding, virality scoring, prompt rewriting and routing (optionally Veo 3.1 / Nano Banana Pro at list price). Optional adapters, behind feature flags: WaveSpeedAI or Higgsfield's own platform API for exact Soul / DoP, sync.so for lipsync-3 at API price, Meshy/Tripo official only where fal lacks a mode.
4. **A sandbox provider (E2B or Modal; Vercel Sandbox if already on Vercel) with a custom image (ffmpeg, ImageMagick, whisper, playwright)** replaces `sandbox_exec` and runs the ffmpeg work for clipify / shorts / subtitles / reframe-by-crop / deflicker.
5. With (1)+(2)+(3)+(4) every model in the Higgsfield catalog is covered except Soul-exact and the platform extras (website builder, Scene Builder 3D, marketplace apps, TikTok publishing), which are deferred or dropped (§6).

## 4. Higgsfield-proprietary features and how we approximate them

Higgsfield's own `provider_name: Higgsfield` rows are Soul 2.0 / Soul Cinema / Soul Cast / Soul Location, Cinema Studio Image 2.5 and Video (v1, v2, 3.0; 3.5 in the CLI), Marketing Studio Image / Video and DTC Ads (`ms_image`), Image Auto, AutoSprite, `higgsfield_preset`, Ad Multiplier ("powered by Seedance 2.5"), Genjutsu (`hf_mult_*`), Text to Speech V2 (an engine selector), Personal Clipper and Virality Predictor, plus the API-only DoP and Soul ID. Higgsfield itself claims to develop only "the Soul family, DOP, Cinema Studio, Keyframes, Soul ID and Soul HEX", everything else is a wrapper, a prompt system or a pipeline. Credit-to-dollar conversion used throughout: 1 credit ≈ $0.033 (Ultra annual $99 / 3 000 cr) to $0.05 (auto-refill at 20 cr per $), list $0.085; top-ups expire after 90 days and subscription credits do not roll over.

### 4.1 Soul 2.0 / Soul ID
Soul is the only model class with no equivalent on fal (zero `higgsfield` entries in the 1 487-model registry) or Kie. Higgsfield trains a Soul ID from 5-20 photos in ~10 minutes (25 credits) and reuses it across Soul V2 / Soul Cinema via `soul_id`; Soul V2 images themselves cost 0.12 credits or come out of a free-gens pool. We ship three tiers: (1) **reference-image identity, no training**: 3-6 curated face/body refs stored as an element and injected into `fal-ai/kling-image/o1` ($0.028, `@Image1…@Image10` maps 1:1 onto `<<<uuid>>>`), `fal-ai/nano-banana-pro/edit` ($0.15; Kie $0.09) or `bytedance/seedream/v5/pro/edit`; good for ~70-80 % of shots, weak on extreme angles; (2) **LoRA training as an opt-in "train character" job**: `fal-ai/flux-2-trainer` ($0.008/step → ≈$8 per 1 000-step identity, inference on `fal-ai/flux-2/lora` at $0.021/MP) or the cheaper `fal-ai/qwen-image-2512-trainer(-v2)` (≈$1 per character) / `fal-ai/z-image-trainer` (inference $0.0085/MP); the pricier `fal-ai/flux-2-trainer-v2` ($0.0255/step) only if quality demands it; (3) **exact Soul behind a feature flag**: Higgsfield's platform API (`/v1/text2image/soul` with `custom_reference_id`, `higgsfield-ai/soul/{standard,2,character,cinema,reference,id}`, 70+ styles via `/v1/text2image/soul-styles`) or WaveSpeed `higgsfield/soul/image-to-image` ($0.09/run, no Soul-ID support). The "Soul look" (UGC realism, unretouched skin) is additionally reproduced with the captured `character-sheet` realism module ("visible fine skin texture with natural pores… no digital smoothing, no beauty filter").

### 4.2 Soul Cast / Soul Location (elements)
Both are the same element store: a reusable `{id, name ≤32 chars, category: character / environment / prop, medias[]}` record referenced in prompts as `<<<element_id>>>` and rewritten to `@name`. Cast = person refs + scene prompt through Kling O1 / Nano Banana Pro edit / Seedream 5 Pro edit (Kie: `nano-banana-pro` `image_input` ≤8, `seedream/5-pro-image-to-image`, `ideogram/character-edit` $0.06-0.12); Location = 2-4 environment refs injected the same way. For video the identical refs go into Kling 3.0 `elements[]` (fal) / `kling_elements[]` (Kie), Kling O3 `reference-to-video`, Seedance 2.x `reference_image_urls`, Wan 3.0 / MiniMax H3 reference inputs, so image and video share one identity source. Higgsfield's elements work with Nano Banana Pro/2, GPT Image 2, Seedream 4.5 / 5 Lite, Cinema Studio 2.5 / Video, Seedance 2.0 and Kling 3.0 but *not* Soul (Soul = trained identity); we mirror that split: elements are references, Soul-ID equivalents are LoRAs.

### 4.3 Cinema Studio (image 2.5, video v2 / 3.0 / 3.5)
A prompt-engineering layer, not a model: camera body (DXL2, RED, Sony, IMAX, ARRI, Panavision), spherical vs anamorphic lenses, focal length 12-135 mm, aperture, sensor profile (VHS / Film / Digital), global genre / style / lighting / colour palette / camera move-set, per-shot settings and a "Director Mode" that stacks up to three camera moves per shot. We compile these controls with an LLM rewriter into model-specific prompts (lens, film stock, lighting, negative tail) over strong bases: images → `bytedance/seedream/v5/pro` or `fal-ai/flux-2-pro` / `fal-ai/nano-banana-pro` (Kie ids for cost); video → `fal-ai/kling-video/v3/pro/*` (multi-shot + native audio, `multi_prompt[]`) or `bytedance/seedance-2.5` (30 s single pass, `genre`, `generate_audio`), Cinema Studio 3.0 shares Seedance 2.0's `genre` enum, 480p-4K ladder and `generate_audio` flag, so a tuned Seedance pipeline is the most likely upstream (`?`). Speed-ramp (`speedramp` auto / linear / slowmo / speedup / impact) is an ffmpeg `setpts` post-step in the sandbox. Camera presets map exactly only through the Higgsfield / WaveSpeed DoP API (§4.7). Observed cost: V2 7.5 credits, 3.0 25 credits per clip.

### 4.4 Marketing Studio / DTC Ads (`ms_image`, `marketing_studio_video`)
Higgsfield's chain is: brand kit auto-extracted from a website URL (logo, colours, fonts, tone) → products by URL or image (≤4 `product_ids`) → format (UGC talking head, product shot with model / standalone, motion, 2D product / Hypermotion / mixed media / SaaS, ads, posters, marketplace) → one of 986 presets, hooks ("what") and settings ("where") for UGC / tutorial / unboxing / review / try-on, or `ad_reference_id` to recreate an analysed reference ad → 12-15 s video at 480p-1080p with a preset or Soul-ID avatar. Observed cost: image 2 credits, video 40 credits. Our pipeline: Playwright screenshot + LLM in the sandbox for the brand kit (stored JSON: palette, fonts, logo asset ids, tone); `fal-ai/birefnet/v2` (Kie `recraft/remove-background`) cutout → hero images on `fal-ai/nano-banana-pro/edit`, `openai/gpt-image-2/edit` for text-heavy packshots or `bytedance/seedream/v5/pro/edit` (inpaint with `fal-ai/flux-pro/v1/fill`); hook script by LLM → avatar clip (Kie `omnihuman-1-5` $0.135/s, `infinitalk/from-audio` $0.015/s, `kling/ai-avatar-pro`; fal `fal-ai/bytedance/omnihuman/v1.5`, or HeyGen / Hedra) → TTS (`fal-ai/elevenlabs/tts/*`, Kie `elevenlabs/text-to-speech-*`) → lipsync (`fal-ai/sync-lipsync/v3` or Kie `volcengine/video-to-video-lip-sync`) → product motion via `bytedance/seedance-2.5/reference-to-video` or `fal-ai/kling-video/v3/pro/image-to-video` with `elements[]` → ffmpeg assembly, overlays and subtitles in the sandbox. The captured UGC workflows (ugc-review / product / try-on / tutorial / unboxing / website, product-photoshoot's 10 modes, thumbnail-generation's 16 frameworks) supply the prompt scaffolds: reference manifest first (`@ImageN`), byte-identical style formula, explicit shot / cut timing, negative tail, "no text" defaults, deterministic overlays in post.

### 4.5 Ad Multiplier
An explicit Seedance 2.5 wrapper (`ad_multiplier` has the same schema as `seedance_2_5`; locked call `mode: "video_edit"`, `duration 8`, `duration_policy: "strict"`, `aspect_ratio: "auto"`, `resolution: "720p"`, `generate_audio: false`, medias = source video + `@Image` refs). We fan out N calls to `bytedance/seedance-2.5/reference-to-video` with the source clip as a video reference plus a change list (fal ≈$0.4730/s at 720p plus 0.6× the input seconds), or to Kie `bytedance/seedance-2-5` at $0.19/s 720p with video input (≈1.5-2× cheaper like-for-like, not 3-5×); cheaper substitutes are Kie `wan/2-7-videoedit` ($0.08-0.12/s), `alibaba/happy-horse/video-edit` and `google/gemini-omni-flash/v1.1/edit`. The rest is deterministic sandbox work we captured from the workflow: `ffprobe` normalisation, `video_analysis_create` scene caption, a Soul-2.0-style prose portrait for missing human refs, prompt-writer asset manifest with a caption-preservation clause and a person-exclusion sentence, then audio re-mux (`adelay/atrim/apad` by measured offset, `-c:v copy -c:a aac -b:a 192k -movflags +faststart`) and gates (duration within max(1/fps, 0.10) s, aspect ±1.5 %, short edge ±8 px, audio present) before `media_confirm`.

### 4.6 Genjutsu (`hf_mult_motion_control`, `hf_mult_replace_object`)

Object swap = `fal-ai/wan/v2.2-14b/animate/replace` / Kie `wan/2-2-animate-replace` (cheap), Kling O3 `video-to-video/edit` (fal) or `kling-3.0-omni/transformation` (Kie), Runway Aleph (Kie $0.03/s, official $0.28/s, WaveSpeed $0.18/s) or Gemini Omni Flash 1.1 `edit` for language-driven swaps. ### 4.7 Presets / DoP (`higgsfield_preset`, `presets_show`)

### 4.8 Clipify / Personal Clipper / Shorts Studio
Clipify takes a YouTube URL and returns 1-20 clips with burned-in subtitles (14 fonts, highlight colour, position, case, face-tracking crop, `segment_seconds`). Our pipeline: ingest (user upload, Supadata / Apify transcript APIs at ~$0.025 per request, YouTube Data API for metadata, yt-dlp violates YouTube ToS for a commercial product) → STT (`fal-ai/wizper`, `fal-ai/elevenlabs/speech-to-text/scribe-v2` $0.008/min, Kie `elevenlabs/speech-to-text` 3 cr; `fal-ai/whisper` is no longer in the registry; Higgsfield's own subtitles workflow uses OpenAI `whisper-1` or local faster-whisper in the sandbox) → LLM segment scoring (Gemini Flash / Claude: hook, pacing, self-contained payoff) → ffmpeg crop to 9:16 with `fal-ai/sam-3/video` or MediaPipe face tracking → ASS subtitles (captured scripts: `audio_to_captions.py` with `--max-words 5 --max-chars 32 --max-gap 0.4`, similarity gate ≥0.90, `subtitle_paper_burn.py --style paper|bold`) → optional `fal-ai/bytedance-upscaler/upscale/video`. Shorts Studio restyles an uploaded clip through one of 44 presets and is "powered by Gemini Omni Flash": `google/gemini-omni-flash/v1.1/edit` ($0.10/s 720p), Kie `google/gemini-omni-flash-1-1` (V2V $0.84 per video) or the cheaper `wan/2-7-videoedit` ($0.08/s). Everything runs in an E2B / Modal sandbox image (ffmpeg, ImageMagick, whisper, Pillow, playwright, fonts) that also serves as our `sandbox_exec`.

### 4.9 Virality predictor / video analysis
No vendor sells a "virality" API; Higgsfield's Virality Predictor (`brain_activity`: Hook Score, Hold Rate, brain heatmap, predicted engagement) and `video_analysis_*` (timed scene captions used by Ad Multiplier) are LLM video understanding. We call the Gemini API (3.1 Pro at $2/1M in, $12/1M out ≤200k, or 3.x Flash with the 2026-09-04 agentic video mode that cuts tokens up to 88 %) with the clip inline or via the File API, ≈300 tokens/s (258 per frame + 32/s audio; 100 tokens/s low-res), so a 60 s clip ≈18k tokens ≈ $0.04 of Pro input, and score against a rubric (hook < 3 s, pattern interrupts, caption density, audio loudness, retention curve proxy). fal alternatives are `fal-ai/moondream3-preview/*` and `openrouter/router/video`; Kie exposes Gemini 3.1 Pro / 3 Flash chat endpoints. Treat the score as unvalidated (defer, §6) but ship the scene-caption half now because Ad Multiplier depends on it.

### 4.10 Dubbing / voices (`dubbing`, `voice_change`, `list_voices`, `create_voice`, `text2speech_v2`)
