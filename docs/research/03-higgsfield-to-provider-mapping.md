# Higgsfield → fal.ai / Kie.ai / other-provider capability mapping (as of 2026-09-05)

## 0. Method and caveats

- Research was done with ~60 web searches plus GitHub code searches / raw fetches. **fal.ai, kie.ai, docs.kie.ai, elevenlabs.io, bfl.ai, ai.google.dev, openai, x.ai, wavespeed.ai, meshy, tripo, topaz, sync.so and minimax vendor sites are egress-blocked in this sandbox**, so fal/Kie facts come from search-engine snippets of those official pages (URLs recorded) and from public GitHub repos that mirror docs.kie.ai (notably `hassanvfx/kie-api-python/docs/kie-ai/raw/...`, `nodaroai/app.nodaro.ai/backend/src/providers/kie/CLAUDE.md`, `justintanner/apicity/packages/provider/cost/src/pricing/kie.ts` which carries "verified 2026-08-06 … 2026-08-25" price snapshots). Anything marked **(unverified)** is memory or inference and must be checked live before it enters a cost model.
- Prices are USD, list price, no volume discounts. fal bills per second/megapixel/generation; Kie bills credits at **1 credit = $0.005** (kie.ai). fal endpoint ids are the string passed to `fal.subscribe(...)`; Kie ids are the `model` field of `POST https://api.kie.ai/api/v1/jobs/createTask` (status: `GET /api/v1/jobs/recordInfo?taskId=`), except Veo (`POST /api/v1/veo/generate`, models `veo3|veo3_fast|veo3_lite`), Suno (`POST /api/v1/generate`, `model: V5|V5_5`), Runway Aleph (`/api/v1/aleph/...`) and Flux Kontext (`flux-kontext-api`).
- Important structural fact: **Higgsfield already resells fal.ai** (its `sonilo_music`, `mirelo_text_to_audio`, `inworld_text_to_speech` entries carry `provider_name: FAL`) and Higgsfield's own developer API (`platform.higgsfield.ai`, SDKs `higgsfield-ai/higgsfield-js`, `higgsfield-ai/higgsfield-client`) exposes third-party models under fal-style ids such as `bytedance/seedream/v4/text-to-image` and `flux-pro/kontext/max/text-to-image`. So the "upstream" for most of the catalog *is* fal or the vendor's official API; the replacement is mostly a re-plumbing exercise, not a model search.

Fidelity legend: **exact** = same upstream model/version; **substitute** = different but comparable model of the same class; **approx** = product-level feature that must be rebuilt as a pipeline/prompt system.

## 2. Proprietary / product-level features and approximation strategies

### 2.1 Soul 2.0 / Soul ID (identity-consistent people)
Higgsfield trains a "Soul ID" from 20+ photos in 3-5 min (help center), MCP says 5-20 photos, ~10 min. Credible options, in order of cost/effort:
1. **Reference-image identity (no training)**: store 3-6 curated face/body refs per character as an "element" and inject into `fal-ai/kling-image/o1` ($0.028), `fal-ai/nano-banana-pro/edit` ($0.15) or `bytedance/seedream/v5/pro/edit`. Kling O1's `@Image1…@Image10` addressing maps almost 1:1 onto Higgsfield's `<<<uuid>>>` placeholders. Quality is good for ~70-80% of shots; weak for extreme angles.
2. **LoRA training**: `fal-ai/flux-2-trainer` ($0.008/step; 9-50 images; deploys to `fal-ai/flux-2/lora` at $0.021/MP), `fal-ai/qwen-image-2512-trainer-v2` ($0.00095/step, 500-step min → ~$0.95/character), `fal-ai/z-image-trainer` (cheap inference $0.0085/MP), legacy `fal-ai/flux-lora-fast-training` / `flux-lora-portrait-trainer`. A 1,000-step FLUX.2 LoRA ≈ $8; Qwen ≈ $1-2. This is the closest analogue to a "trained identity layer" and gives the stable face across presets that Soul ID promises.
3. **Exact Soul**: Higgsfield's own developer API (`/v1/text2image/soul`, "reference_id" from Soul training per github.com/higgsfield-ai/skills) or WaveSpeed `higgsfield/soul/image-to-image` ($0.09/run). Keep as optional adapter if clients demand the Soul aesthetic.
Recommendation: ship (1) as default, (2) as an opt-in "train character" job, (3) behind a feature flag.

### 2.2 Soul Cast / Soul Location
Same element store; Cast = person refs + scene prompt via `kling-image/o1`/`nano-banana-pro`; Location = 2-4 environment refs; for video, pass the same refs into Kling 3.0 `kling_elements` (Kie) or Seedance 2.x `reference_image_urls` so image and video share one identity source.

### 2.3 Cinema Studio (image + video)
A prompt-engineering layer (shot type, lens/focal length, camera move, lighting, film stock, aspect ratio, negative prompts) compiled by an LLM into model-specific prompts. Base models: images → `bytedance/seedream/v5/pro` or `fal-ai/flux-2-pro` (Kie ids for cost); video → `fal-ai/kling-video/v3/pro/*` (multi-shot + native audio) or `bytedance/seedance-2.5` (30 s single pass). Camera presets map onto Higgsfield DoP only if you use the Higgsfield/WaveSpeed DoP API; otherwise encode each of the 62 presets as a prompt template + optional first/last-frame trick (Kling 3.0 `image_urls` 1-2 frames; Seedance `first_frame_url`/`last_frame_url`).

### 2.4 Marketing Studio / DTC ads / ad hooks
Chain: product photos → `birefnet/v2` cutout → product hero images (`nano-banana-pro/edit`, `gpt-image-2/edit` for text-heavy packshots, `seedream v5 pro edit`) → hook script (LLM) → avatar clip (`omnihuman-1-5`, `kling/ai-avatar-pro`, `infinitalk/from-audio` on Kie; or HeyGen/Hedra) → TTS (`elevenlabs`/`minimax`) → lipsync (`sync-lipsync/v3`) → assembly in sandbox (ffmpeg) → subtitles. Brand kit = stored JSON (palette, fonts, logo asset ids, tone) injected into prompts and overlays. The 16 Higgsfield SKILL.md workflows (ugc-*, product-photoshoot, thumbnail-generation, narrator, faceless-video…) are prompt chains you can re-author against these ids.

### 2.5 Ad Multiplier (Seedance 2.5 video edit)
`bytedance/seedance-2.5/reference-to-video` with the source ad as `reference_video` plus a change list; fan-out N variants in parallel. Cheaper alternatives: Kie `bytedance/seedance-2-5` (≈3-5× cheaper), `wan/2-7-videoedit` ($0.08-0.12/s), `alibaba/happy-horse/video-edit`.

### 2.6 Genjutsu (motion control / replace object)
Motion transfer = Kling 3.0 motion control (fal or Kie ids above; exact). Replace = `wan/v2.2-14b/animate/replace` (cheap), Runway Aleph ($0.28/s official; $0.18/s WaveSpeed; via Kie runway-api), or Gemini Omni Flash 1.1 edit (language-driven). Higgsfield's "hf_mult_*" were themselves Kling-3.0-based per its MCP docs, so fidelity is high.

### 2.7 Clipify / Shorts Studio
Ingest (yt-dlp is against YouTube ToS for a commercial product; prefer user-uploaded files, Supadata/Apify transcript APIs at ~$0.025/request, or YouTube Data API for metadata) → STT (`fal-ai/whisper`, or ElevenLabs Scribe via Kie `elevenlabs/speech-to-text`) → LLM segment scoring (Gemini Flash/Claude) → ffmpeg crop to 9:16 with `sam-3/video` or MediaPipe face tracking → burned ASS subtitles → optional `topaz`/`bytedance` upscale. Run in E2B/Modal with a custom image (ffmpeg, ImageMagick, whisper, playwright), which is exactly what Higgsfield's `sandbox_exec` offers.

### 2.8 Virality predictor / video analysis
Gemini 3.1 Pro or Flash with the video as inline/File-API input; score against a rubric (hook <3 s, pattern interrupts, caption density, audio loudness). Cost ≈ 300 tokens/s → a 60 s clip ≈ 18k tokens ≈ $0.04 on 3.1 Pro input; Flash agentic mode cheaper still.

### 2.9 Dubbing / voice change / voices
Use ElevenLabs official API for dubbing ($0.33-0.50/min), IVC/PVC and voice library; keep fal wrappers for TTS/voice-changer. Kie has no dubbing or voice-clone endpoints.

### 2.10 Reframe, outpaint, upscale, background removal
All exact or near-exact on fal (Luma reframe, FLUX.2 outpaint, Topaz/ByteDance upscalers, BiRefNet). Kie covers image upscale/bg-removal/reframe via Topaz/Recraft/Ideogram, but no video reframe or video matting.

### 2.11 Website builder, Scene Builder 3D, marketplace apps, TikTok publishing
See §3, defer or drop.

## 3. Provider prioritisation (fewest integrations for ~95% of usage)

1. **fal.ai (mandatory, ~85% of catalog).** Every image model except Soul, every video model incl. Kling 3.0/turbo/4K/motion-control, Seedance 2.0/2.5, Veo 3.1, Wan 2.6/2.7/3.0, HappyHorse, Grok, MiniMax, FLUX 3, Gemini Omni; all audio (Seed Audio, Qwen TTS, ElevenLabs TTS/voice-changer, MiniMax, VibeVoice, Sonilo, Mirelo, Inworld); all 3D (Meshy 5/6/7, Tripo H3.1, Hunyuan3D 3/3.1, SAM 3D); upscalers, BiRefNet, SAM 3 video, Luma reframe, sync-lipsync v3; LoRA trainers. One queue API (`fal.subscribe`/`queue.submit` + webhooks), one storage, one billing. This alone replaces the Higgsfield `generate_*`, `upscale_*`, `remove_background`, `reframe`, `outpaint_image`, `voice_change`, `generate_3d`, `motion_control` tools.
2. **Kie.ai (cost arbitrage + gap filler, ~10%).** Same-model prices are materially lower: Seedance 2.5 720p+audio ≈$0.17/s vs fal ≈$0.47/s; Kling 3.0 pro+audio $0.135/s vs $0.168/s; Veo 3.1 fast $0.30/8 s vs $1.20; Grok video 720p $0.0225/s vs $0.07/s; GPT Image 2 $0.03-0.08 vs token billing; Seedream 5 Pro $0.035-0.07 vs $0.0675-0.135. Unique on Kie: Suno V5/V5.5 ($0.06/song), avatars (`omnihuman-1-5`, `kling/ai-avatar-pro`, `infinitalk/from-audio`), Runway Aleph, Sora 2/2 Pro, Midjourney, Ideogram character/reframe, Wan 2.2 Animate. Risks: unofficial reseller of Google/OpenAI/Kling models (ToS/uptime exposure), no voice cloning/dubbing/3D/video-matting, schema quirks (`multi_shots` required, ratio enums per model → 422 aborts). Put it behind a provider-router with per-model fallback to fal.
3. **Google Gemini API (Vertex optional).** Video understanding/virality/prompt rewriting/routing; optionally direct Veo 3.1 + Nano Banana Pro at list price.
4. **ElevenLabs official API.** Dubbing, voice cloning, voice library (not available via fal/Kie).
5. **Sandbox provider** (E2B or Modal; Vercel Sandbox if already on Vercel) for clipify/shorts/ffmpeg/subtitles and as the `sandbox_exec` tool.
6. **Optional adapters:** WaveSpeedAI or Higgsfield platform API for exact Soul/DoP; sync.so official for lipsync-3 at API price; Meshy/Tripo official only if fal lacks a specific mode (rig animation library).
7. **Defer:** TikTok Content Posting API (audit), Cloudflare Workers for Platforms (website builder).

With (1)+(2)+(3)+(4)+(5) you cover every model in the Higgsfield catalog except Soul-exact and the platform-level extras.
